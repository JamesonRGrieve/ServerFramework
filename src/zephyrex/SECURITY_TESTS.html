Category 5 — Not Relevant to This Project

CSRF (Corpus §19)

Zephyrex is an API-only server. Authentication uses JWT in the Authorization header, not cookies. Browsers do not auto-attach Authorization headers cross-origin, so CSRF is architecturally eliminated.

MCP — all sections (Corpus §§6, 7, 25–31)

No MCP implementation exists in the codebase. Zero files, endpoints, handlers, or protocol support. When MCP is implemented, all 7 MCP corpus sections become mandatory. This should be a blocking gate on any MCP PR.

OAuth / authorization-server (Corpus §5)

The OAuth consumer/provider extensions exist as code but are in the unported-extensions set (broken imports, excluded from test collection). When ported, the full OAuth corpus (§5) becomes mandatory — PKCE, redirect validation, issuer verification, scope escalation, and all token-lifecycle tests.

Dependency / supply-chain (Corpus §44)

CI-level concern, not a unit/integration test. The pre-commit ratchet already verifies lockfile integrity and minor-version freshness. Vulnerability scanning (CVE databases) belongs in CI pipeline tooling (e.g., pip-audit, Dependabot), not in the pytest suite.
